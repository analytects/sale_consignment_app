Operar consignaciones de principio a fin

Registre lo que entrega a un cliente, solicite aprobación y confirme la recepción en la ubicación de consignación. Luego cree pedidos por lo vendido y consulte las devoluciones y documentos vinculados.

Módulo
sale_consignment_app
Versión
19.0.1.1
Aplicación
Sale Consignment
Rol
Usuario de consignaciones

Antes de empezar

  • Usuario agregado al grupo Sale Consignment Feature.
  • Almacén, ruta y almacén de venta asignados en sus preferencias cuando la vista está activa; si no, selecciónelos en cada orden.
  • Cliente y productos marcados para consignación.
01

Crear una orden de consignación

La orden registra cliente, ruta de inventario, fecha, productos y cantidades que se entregarán.

  • DóndeConsignación›Órdenes de Consignación
  • QuiénSolicitante

  1. Abra Órdenes de Consignación y pulse Nuevo.

  2. Seleccione el cliente, almacén, ruta, fecha y almacén de venta; los campos pueden venir completados desde sus preferencias.

  3. Agregue un producto marcado para consignación, indique la cantidad y revise el precio de lista.

  4. Para un producto con lotes o números de serie, abra Register lots, packs, location y asigne el lote y la cantidad.

  5. Guarde la orden.

Importante. En sb-19 la vista de Preferencias que agrega los valores predeterminados del usuario está inactiva. Si no ve esos valores en su usuario, seleccione manualmente almacén y ruta en cada orden.

Resultado. La orden queda en estado Quotation.

02

Enviar la solicitud para aprobación

El solicitante cambia la orden de cotización a espera de aprobación.

  • DóndeConsignación›Órdenes de Consignación›orden
  • QuiénSolicitante

  1. Abra la orden guardada y compruebe que cliente, productos y cantidades estén correctos.

  2. Pulse Consignment Request.

  3. Confirme que el estado cambió a Waiting Approval.

Resultado. La orden está lista para que un aprobador la revise.

03

Aprobar y reservar existencias

El aprobador crea la transferencia de ingreso y solicita la reserva de las cantidades.

  • DóndeConsignación›Órdenes de Consignación›orden
  • QuiénAprobador

  1. Abra la orden en espera y revise la ruta y los productos solicitados.

  2. Pulse Approve. Odoo crea una transferencia interna y reserva las cantidades disponibles.

  3. Abra Transferencias para ver el movimiento generado.

  4. En Inventario, procese y valide la transferencia a la ubicación de consignación.

  5. Regrese a la orden y pulse Confirm después de validar la transferencia.

Importante. Si pulsa Confirm antes de validar la transferencia, Odoo mostrará un error. Abra el movimiento en Inventario, valide su recepción y vuelva a la orden.

Resultado. La orden queda en estado Consignment y permite crear pedidos de venta.

04

Crear un pedido por los productos vendidos

El asistente prepara un pedido de venta con las cantidades que el cliente comprará.

  • DóndeConsignación›Órdenes de Consignación›orden›Create Sale Order
  • QuiénVentas

  1. En la orden confirmada, pulse Create Sale Order.

  2. Indique la cantidad que se venderá ahora para cada producto; puede reservar el remanente para otro pedido.

  3. En productos con lotes o números de serie, abra el detalle de la línea y capture los lotes y cantidades correspondientes.

  4. Revise cliente, almacén de venta y precio de lista; pulse Create Sale Order para crear y confirmar el pedido.

  5. La orden de venta creada se abre automáticamente. Para volver a la consignación, use la navegación anterior.

Importante. El botón crea y confirma la venta de inmediato. Revise las cantidades y lotes antes de pulsarlo. El campo Unit Price del asistente no es el precio copiado al pedido; se utiliza Precio Lista.

Resultado. El pedido queda vinculado a la consignación y reduce la cantidad restante.

05

Consultar ventas, transferencias y devoluciones

Los botones inteligentes de la consignación abren los documentos vinculados.

  • DóndeConsignación›Órdenes de Consignación›orden
  • QuiénUsuario de consignaciones

  1. Abra una orden que tenga movimientos relacionados.

  2. Pulse Transferencias para revisar las transferencias cuyo origen es la orden.

  3. Pulse Órdenes de venta para consultar los pedidos creados desde esa consignación.

  4. Pulse Devoluciones para revisar las transferencias generadas por devoluciones.

Consejo. Los botones inteligentes aparecen cuando hay documentos asociados. El campo Cantidad entregada y el Monto facturado ayudan a comparar el saldo solicitado y vendido.

06

Cancelar una orden y revisar la devolución automática

Al cancelar, el módulo intenta devolver las cantidades no vendidas de transferencias ya completadas.

  • DóndeConsignación›Órdenes de Consignación›orden›Cancel
  • QuiénAprobador

  1. Antes de cancelar, revise las cantidades vendidas y las transferencias completadas.

  2. Pulse Cancel.

  3. Abra Devoluciones para revisar las transferencias de retorno creadas y procese cualquier movimiento que lo requiera.

Importante. Solo se consideran automáticamente las transferencias de ingreso en estado completado. Si hay una transferencia pendiente, resuélvala desde Inventario.

Nota. El botón Return no está disponible en la pantalla y no existe una acción de desreservar en el formulario. Cancelar es la acción que genera la devolución automática del saldo no vendido.

07

Marcar como terminada una orden vendida

Cuando ya no quedan unidades por gestionar, el aprobador puede cerrar la orden.

  • DóndeConsignación›Órdenes de Consignación›orden›Done
  • QuiénAprobador

  1. Compruebe que las ventas y devoluciones estén registradas.

  2. En la orden que está en estado Sale, pulse Done.

  3. Confirme que el estado cambió a Done.

Importante. En sb-19, una vista de Studio deja Done visible también en Cotización y Aprobado. Úselo solo después de completar las ventas; el botón cambia el estado directamente.

Nota. Done no procesa devoluciones ni completa movimientos de Inventario.

08

Preparar el reporte de ventas en consignación

El asistente permite consultar líneas de venta por fechas y, opcionalmente, filtrar productos o clientes.

  • DóndeConsignación›Reportes›Sale Consignment
  • QuiénUsuario de ventas

  1. Abra el asistente Sale Consignment.

  2. Seleccione Consignment Sale Order Report.

  3. Indique Start Date y End Date. Si es necesario, agregue productos o clientes para filtrar.

  4. Pulse Print PDF Report.

Importante. El filtro de fechas utiliza límites estrictos; puede omitir registros del día inicial o final. El PDF también muestra la fecha final en los dos rótulos del periodo.

Nota. El reporte detallado por orden tiene un defecto conocido que puede impedir la generación del PDF; no lo use como salida validada.

09

Solicitar el reporte detallado de una orden

El asistente ofrece una salida con cantidades solicitadas, entregadas, facturadas y montos.

  • DóndeConsignación›Reportes›Sale Consignment
  • QuiénUsuario de ventas

  1. En el asistente, seleccione Sale Consignment Order Report.

  2. Elija la Consignment Order que quiere consultar.

  3. Pulse Print PDF Report.

Importante. La plantilla intenta leer total_qty_invoiced, campo que no existe en las líneas de consignación. La impresión puede fallar; consulte la orden y su cantidad facturada directamente mientras se corrige.
